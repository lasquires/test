Exceptions open a drawer — not a new workflow.

Delay, hold, dose change, infusion reaction, not-given, or access problem reveals only the extra fields needed for that exception and automatically creates the audit trail.

Prototype purpose: demonstrate an exception-driven systemic-therapy workflow. It is not an ordering system and is not a source of clinical dosing guidance. Regimen names and schedules are included to make the interaction realistic; a production system should load only institutionally approved, version-controlled protocols.
